## ✨ Fitur Aplikasi

### 🔧 1. Manajemen Pelanggan
- Tambah data pelanggan  
- Edit data pelanggan  
- Hapus pelanggan  
- Tampilkan daftar pelanggan  

### 🛠️ 2. Manajemen Mekanik
- Tambah data mekanik  
- Edit data mekanik  
- Hapus mekanik  
- Tampilkan daftar mekanik  

### 📅 3. Manajemen Reservasi Bengkel
- Tambah reservasi baru  
- Pilih pelanggan  
- Pilih mekanik  
- Pilih layanan servis  
- Tentukan tanggal & waktu  
- Edit & hapus reservasi  
- Menampilkan tabel daftar reservasi lengkap dengan relasinya  

### 📄 4. Validasi & Notifikasi
- Validasi form Laravel  
- Flash message (success/error)

### 📊 5. Dashboard  
- Total pelanggan  
- Total mekanik  
- Total layanan  
- Total reservasi sukses  
- Statistik dalam bentuk card
